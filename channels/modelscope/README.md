# ModelScope 渠道 · 配置获取指南

本渠道只需要一个配置项：**站点 Cookie**。它就是你在浏览器里登录 modelscope.cn 的身份凭证。

## 需要填什么

| 配置项 | 是否必填 | 说明 |
|---|---|---|
| 站点 Cookie | 必填 | 浏览器里 modelscope.cn 的完整 Cookie 字符串 |

## 抓取步骤（约 1 分钟）

1. 用 Chrome/Edge 打开 `https://modelscope.cn/my/overview`，确认右上角是**已登录**状态
2. 按 **F12** 打开开发者工具 → 点顶部 **Network（网络）** 标签
3. 按 **F5** 刷新页面，在请求列表里**随便点一个发往 modelscope.cn 的请求**
4. 右侧切到 **标头(Headers)** → 下拉到 **请求标头(Request Headers)** → 找到 **`Cookie`** 这一行
5. 右键该行的值 → 复制值（或手动全选复制），粘贴到任务的「站点 Cookie」输入框

> 更省事的办法：F12 → **应用(Application)** 标签 → 左侧 **Cookie** → `https://modelscope.cn`，
> 把里面所有条目按 `名称=值` 用 `; ` 拼起来也可以，但直接复制请求头的 Cookie 更不容易错。

## 常见问题

- **任务做什么**: 1.1.0 起任务会自动触发魔搭的"每日登录奖励"(每天首次登录送魔方, 额度以平台实际为准), 并展示签到前后余额变化; 当天若已通过浏览器登录领取过, 任务会显示"无增量"。
- **任务报"Cookie 已失效(HTTP 401/403)"**: Cookie 过期了。重新登录 modelscope.cn，按上面步骤重新抓一次，更新到任务配置里即可。
- **多账号**: 一个任务对应一个账号。浏览器登录 A 账号抓一份 Cookie 建 A 的任务，再切换登录 B 账号抓一份建 B 的任务。
- **安全提醒**: Cookie 等同于登录凭证，不要发给他人或贴到公开场合；只保存在本平台的任务配置中。
