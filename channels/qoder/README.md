# Qoder 渠道 · 配置获取指南

本渠道需要两个配置项：**访问凭证** 和 **站点区域**。

## 需要填什么

| 配置项 | 是否必填 | 说明 |
|---|---|---|
| 访问凭证 | 必填 | `pt-` 开头的 PAT（推荐）或 `dt-`/`jt-` 令牌 |
| 站点区域 | 必填 | 国内版选 `qoder.com.cn`，国际版选 `qoder.com` |

## 方式一：创建 PAT（推荐，长期有效）

1. 用浏览器打开并登录 Qoder：
   - 国内版：`https://qoder.com.cn`（凭证选「国内版」区域）
   - 国际版：`https://qoder.com`（凭证选「国际版」区域）
2. 点右上角头像 → **设置（Settings）** → 找到 **Personal Access Token（个人访问令牌）**
3. 点 **创建（Create）**，随便起个名字，生成一串 **`pt-` 开头**的令牌
4. 复制整串令牌，粘贴到任务的「访问凭证」输入框

> PAT 长期有效，不用担心过期；本渠道每次运行会自动用它换取会话令牌，无需手动刷新。

## 方式二：使用客户端/代理工具的会话令牌

如果你在用 Qoder 桌面客户端，或已经在用 CLIProxyAPI / 9router 这类代理工具，
可以直接使用它们保存的令牌：

- `dt-` 开头：设备令牌（约 30 天有效，过期需重新获取）
- `jt-` 开头：任务令牌（由工具自动刷新）

获取方法（任选其一）：

- CLIProxyAPI：打开 `%USERPROFILE%\.cli-proxy-api\` 目录下 `qoder-` 开头的 `json`
  文件，复制其中 `access_token` 字段的值
- 抓包：Qoder 客户端登录后，用 Fiddler/mitmproxy 等工具查看发往
  `openapi.qoder.com.cn`（或 `openapi.qoder.sh`）请求头里的
  `Authorization: Bearer xxx`，复制 `xxx`

## 区域怎么选

凭证从哪个站点创建，区域就选哪个：

| 你的账号登录的是 | 区域选 |
|---|---|
| qoder.com.cn（国内版） | 国内版 qoder.com.cn |
| qoder.com（国际版） | 国际版 qoder.com |

区域选错会报「凭证无效(HTTP 401)」。

## 签到说明

- 每日权益通过 Qoder 的 **campaigns 活动系统**领取，每天一般 100 积分左右，
  实际额度以平台活动为准
- 已领取过的日子里重复运行会提示「今日已签到(幂等命中)」，不会重复加分
- 当天没有可领取的活动时提示「今日暂无可领取的权益活动」，属正常状态
- 任务消息和「剩余积分」列会显示签到前后的积分变化

## 设备标识（2026-09 下旬起必需）

Qoder 服务端只给带**设备标识请求头**（`Cosy-MachineToken` / `Cosy-MachineId` 等）
的请求下发每日领取活动；缺失时**国际版**账号活动列表只剩 `VIEW_DETAILS`
订阅促销，无可领积分活动（CN 区通常不受影响）。本渠道处理方式：

- **本机（装了 Qoder 客户端的 Windows）**：脚本自动调用客户端自带组件
  `resources/umid/runtime-info.exe` 获取标识，无需配置。
- **服务器（无客户端）**：在开发机执行 `python tools/qoder_device.py` 生成
  `data/qoder_device.json`，上传到服务器的 `/opt/auto-checkin/data/qoder_device.json`
  （`chmod 600`）。渠道脚本会自动读取；也可用环境变量 `QODER_DEVICE_JSON` 指定路径。
- 标识文件内容是设备指纹（非账号凭证），仍请妥善保管、不要外传。

已知限制（2026-09-29 实测观察，机制以官方风控为准）：

- 同一设备标识当天完成一次领取后，同机其他账号的可领活动可能被上游收回，
  多账号国际版建议分散设备或以每日调度结果为准；
- 设备标识可能与出口 IP 绑定校验，服务器直连未必总能拿到活动，
  异常时可在客户端里手动确认当日活动状态；
- 个别账号上游未下发每日活动（列表只有订阅促销），属账号资格问题，
  脚本无法绕过，只能等官方下发或在客户端里手动查看。

## 常见问题

- **报「凭证无效或已过期(HTTP 401)」**：令牌失效或区域选错。PAT 长期有效推荐优先使用；
  `dt-` 令牌过期后需重新获取。
- **报「领取失败」**：可能活动已被上游调整，查看执行日志里的详细原因；
  也可以打开 Qoder 客户端的签到/福利页面手动确认当日活动状态。
- **多账号**：一个任务对应一个账号。不同账号分别创建任务，各填各的凭证。
- **安全提醒**：凭证等同于账号身份，不要发给他人或贴到公开场合；只保存在本平台的任务配置中。
