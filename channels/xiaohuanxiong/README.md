# 商汤小浣熊 渠道 · 配置获取指南

本渠道用于领取小浣熊(xiaohuanxiong.com)的**每日登录积分**。小浣熊没有单独的签到按钮，
每天首次调用登录态接口时服务端自动发放每日积分(当天 23:59:59 清零)，本渠道就是替你完成这一次调用。

只需要一个东西：**访问令牌**。它直接填在本平台的任务配置里，不依赖 9router、客户端或任何本机软件；
部署在 Linux 服务器上也能正常使用。

## 需要填什么

| 配置项 | 是否必填 | 说明 |
|---|---|---|
| 访问令牌 | 二选一 | 单账号填这里，粘贴 JWT 令牌 |
| 账号列表(多账号) | 二选一 | 每行一个账号，格式 `TOKEN#备注`。备注可省略，可含 `#` |
| 仅测试(不实际请求) | 否 | 勾选后只加载账号、不发请求，用于验证配置 |

「访问令牌」和「账号列表」可以同时使用，脚本会按令牌去重后逐个签到。

## 手动获取令牌

令牌是一串以 `eyJ` 开头、约 430 个字符的 JWT。下面两种方式任选一种，**全程不需要任何第三方工具**。

### 方式一(推荐): 从浏览器网页版复制

**前提**: 在 Chrome / Edge 里登录过网页版小浣熊。

1. 打开 `https://xiaohuanxiong.com/`，确认页面右上角显示你的账号(已登录)；
2. 按 **F12** 打开开发者工具；
3. 点顶部的 **Application(应用)** 标签(中文版叫「应用」)；
4. 左侧栏找到 **Storage(存储) → Cookies → `https://xiaohuanxiong.com`**，点击它；
5. 右侧会出现一张 Cookie 表格，在 **Name** 列里找到 **`xhx_token`**；
6. 点中这一行，在下方 **Value(值)** 里**全选并复制**整串内容(以 `eyJ` 开头，约 430 个字符)；
7. 回到本平台「新建任务」弹窗，粘贴到「访问令牌」输入框。

**找不到 Application 标签？** 换用这个办法：

1. 保持已登录状态，按 **F12** → 点 **Network(网络)** 标签；
2. 按 **F5** 刷新页面；
3. 在请求列表里点任意一条发往 `xiaohuanxiong.com` 的请求；
4. 右侧 **Headers(标头)** → 下拉到 **Request Headers(请求标头)** → 找到 **`Cookie`** 一行；
5. 在 Cookie 里找到 `xhx_token=...`，复制 `xhx_token=` **后面**、下一个 `;` **前面**的那串值；
6. 粘贴到「访问令牌」。整段 Cookie 直接粘贴也可以，脚本会自动从中取出 `xhx_token`。

说明: 网页版令牌首次使用前需要调用一次 `iam/confirm` 激活，脚本会自动完成，你不需要手动操作。

### 方式二: 从本机小浣熊客户端复制

**前提**: 这台电脑安装并登录过小浣熊客户端(仅复制令牌时需要)。

1. 按 `Win + R` 打开「运行」，粘贴下面这行后回车：
   `%USERPROFILE%\.office-raccoon\agent\config`
2. 在打开的文件夹里找到 `auth.json`，用记事本或 VS Code 打开；
3. 搜索 `"access_token"`，复制冒号后面那串以 `eyJ` 开头的长文本(约 430 个字符，**不要带引号**)；
4. 粘贴到任务的「访问令牌」输入框。

macOS / Linux 对应路径: `~/.office-raccoon/agent/config/auth.json`

⚠ 客户端切换账号或点「退出登录」会让这个令牌失效，优先用方式一。

## 多账号怎么填

「账号列表」每行一个账号，令牌和备注用 `#` 分隔:

`eyJhbGciOi...第一串令牌...#主号`

`eyJhbGciOi...第二串令牌...#小号A`

- 备注可省略，省略时自动命名为「账号1」「账号2」……
- 同一个令牌重复出现会自动去重
- 一个任务可以签多个账号；也可以一个账号建一个任务，自行选择

## 建议的定时规则

- 每日积分**当天 23:59:59 清零**，越早领越好，建议 `30 0 * * *`(每天 00:30)或 `5 9 * * *`。
- 接口是幂等的：同一天重复运行不会重复发积分，多跑几次没有副作用。
- 令牌约 **30 天**过期，到期后任务会报「凭证无效或已过期(HTTP 401)」，重新取令牌更新任务即可。
  平台任务列表的「令牌有效期」列会显示剩余天数，剩 7 天内标红提醒。

## 常见问题

- **报「未找到任何账号」**: 任务配置里既没有「访问令牌」也没有「账号列表」。按上面任一方式取一个令牌填入即可。
- **报「凭证无效或已过期(HTTP 401)」**: 令牌过期或被吊销。重新获取令牌并更新任务。浏览器会话与客户端会话互不影响，优先用浏览器方式。
- **报「令牌需要先激活」后仍失败**: 说明 `iam/confirm` 没成功，通常是令牌已失效，重新取一个即可。
- **日志显示「今日已签到(今日每日积分已发 300)」**: 属于正常成功。说明当天已经领过，没有重复发放，当前可用积分照常展示。
- **日志显示「签到完成, 今日暂无新发放」**: 接口调用成功但服务端没有下发新积分。可能是当天已通过其他途径领取，或账号权益状态特殊；可稍后手动再跑一次确认。
- **签到后积分反而变少**: 每日积分当天清零，若在接近 23:59 时运行，可能先扣了到期积分。建议固定在 00:30 之后运行。
- **能部署在 Linux 服务器上吗**: 可以。渠道只依赖 Python 标准库，只需服务器能访问 `xiaohuanxiong.com`；令牌在创建任务时填入，不读取任何本机文件。
- **安全提醒**: 令牌等同于账号登录凭证，只保存在本平台任务配置中，不要发给他人或粘贴到公开场合；平台日志只显示令牌前 6 位。
